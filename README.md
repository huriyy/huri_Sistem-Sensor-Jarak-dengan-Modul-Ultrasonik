# Sistem Sensor Jarak dengan Buzzer Berbasis Arduino

Sistem ini menggunakan sensor ultrasonik untuk menghitung jarak antara sensor dengan objek melalui pantulan gelombang dengan objek yang menjadi dasar keputusan dari sistem percabangan. Buzzer akan berbunyi ketika sistem keputusan mengeksekusi perintah buzzer.
